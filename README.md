# 💰 ميزانية Pro+ — تطبيق أندرويد

تطبيق لإدارة المصروفات والميزانية الشخصية بالعربي، مبني بـ **Capacitor 8**.

## 📥 تحميل آخر نسخة
**[⬇️ تحميل BudgetPro.apk](../../releases/latest/download/BudgetPro.apk)**
ملف `BudgetPro.aab` موجود في صفحة [Releases](../../releases/latest) للرفع على Google Play.

## ✨ المميزات
- تتبع يومي للدخل والمصروفات حسب الفئات، وإحصائيات ورسوم بيانية
- مساعد ذكاء اصطناعي (Gemini / Groq)
- 🔔 إشعارات حقيقية: تذكير يومي، وتنبيهات 75% و90%، وتنبيه ميزانية الفئة، ومواعيد الديون
- 🔐 شاشة أذونات (الإشعارات والتخزين) تطلب موافقة المستخدم
- 📁 تصدير JSON و CSV والتقرير إلى `Documents/BudgetPro` مع قائمة المشاركة
- 🔒 قفل التطبيق برمز سري، و 🙈 وضع إخفاء المبالغ (يحجب كمان لقطات الشاشة وشاشة التطبيقات الأخيرة)
- 🌓 مظهر فاتح / داكن / تلقائي حسب الجهاز، وألوان شريط الحالة بتتغير مع المظهر
- 🤝 الديون والسلف، و 🕌 حاسبة الزكاة، و 🎯 ميزانية لكل فئة، و 🔮 توقعات آخر الشهر
- ⬅️ دعم زر الرجوع في أندرويد، واختصارات على أيقونة التطبيق، واهتزاز خفيف
- 💾 نسخة احتياطية تلقائية داخل تخزين التطبيق الأصلي، وتذكير بعمل نسخة احتياطية

## 🛠️ البناء
البناء بيتم تلقائيًا بـ GitHub Actions مع كل push على `main`، وبيتنشر Release جديد.

محليًا:
```bash
npm ci
npx cap sync android
cd android && ./gradlew assembleRelease
```
مفتاح التوقيع محفوظ في GitHub Secrets، وهي: `KEYSTORE_BASE64` و `KEYSTORE_PASSWORD` و `KEY_ALIAS` و `KEY_PASSWORD`.
